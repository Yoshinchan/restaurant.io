
# Ember & Oak — Restaurant Website Demo

A responsive restaurant website built using HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Restaurant introduction and sample menu
- Mobile navigation menu
- Contact email link
- Automatic copyright year

## Run locally
Open `index.html` in a browser or use the VS Code Live Server extension.

## Important
This is a fictional practice project. Menu items, prices, imagery, and contact details are illustrative and must be replaced with authorized content before commercial use.

## Technologies
- HTML5
- CSS3
- JavaScript
